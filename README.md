# Counter App

A simple yet functional counter application with increment, decrement, reset, and save/load history functionality.

## Features

- Increment/Decrement counter value
- Reset counter to zero
- Save current value to history
- Load previously saved values
- Clean, minimal UI
- Deployed via GitHub Pages

## Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla)
- GitHub Actions (CI/CD)
