## 🎯 Overview

A **clean and functional counter app** with more than just +/- buttons. Features **history tracking**, save/load functionality, and a polished UI with smooth animations.

---

## ✨ Features

| Feature | Description |
|:---|:---|
| ➕ **Increment** | Increase counter by 1 |
| ➖ **Decrement** | Decrease counter (stops at 0 or goes negative) |
| 🔄 **Reset** | Reset counter to zero |
| 💾 **Save History** | Save current count to history list |
| 📂 **Load History** | Restore any previously saved count |
| 🎨 **Color Feedback** | Counter changes color based on value (positive/zero/negative) |
| ✨ **Animations** | Smooth transitions on every interaction |
